# `feature/imposition-export-options` 機能追加まとめ

この文書は、`main` から `feature/imposition-export-options` までに追加された機能をまとめたものです。

## 概要

このブランチでは、印刷・レーザー加工向けの面付け出力を中心に、SVG絵柄入力、書き出しプレビュー、Illustrator出力を拡張しました。

主な追加内容は次のとおりです。

- 任意サイズの面付けと自動複製
- 絵柄と台座の独立面付け
- 絵柄数と台座数が同数になる完成セット数の最大化
- 面付け間隔と外周余白の調整
- SVGをフィギュア絵柄として読み込む機能
- SVGの350dpiラスタライズ
- 書き出しプレビューの常時表示
- Illustrator向け出力の追加・拡張
- 赤色カットライン、左右反転、外枠などの加工向け設定

## SVG絵柄入力

従来のPNGに加えて、SVGをフィギュア絵柄として読み込めます。

- ドラッグ＆ドロップとファイル選択の両方に対応
- `viewBox` または `width` / `height` から縦横比を取得
- SVGをブラウザ内でRGBA画像へ変換し、既存の輪郭・重心解析へ接続
- SVG内のスクリプト、イベント属性、外部参照を除去してから描画
- ブラウザがSVG Blobの直接デコードに対応していない場合も、Canvas経由で読み込み可能

### SVGの解像度

SVGは、指定中のフィギュア高さに対して350dpiになるようラスタライズします。

フィギュア高さには絵柄外側の寸法も含まれるため、実際の画素数は次の絵柄高さを基準に決定します。

```text
絵柄高さ = フィギュア高さ
         - カットライン余白 × 2
         - アクリル板の持ち上げ量
         - 板厚

縦ピクセル数 = 絵柄高さ(mm) ÷ 25.4 × 350
```

## 書き出し設定

エクスポートパネルに次の設定を追加しました。

| 設定 | 内容 |
| --- | --- |
| 絵と台座の間隔 | 通常配置における絵柄パーツと台座パーツの間隔 |
| 枠をつける | 書き出し図形の外側へ枠を追加 |
| 枠の余白 | 図形と追加枠の間隔 |
| 面付けする | 指定した用紙サイズへ複製配置 |
| 絵柄と台座を別々に面付けする | 絵柄と台座を別領域へ独立配置 |
| 面付け幅・高さ | 面付け用紙の実寸。既定値はA4の210 × 297mm |
| 面付けの隙間・外周余白 | パーツ間隔と用紙外周からの余白。既定値は5mm |
| カットラインのみ赤で出力する | 加工線を赤、補助線を非表示にして出力 |
| 絵柄を左右反転する | 絵柄画像と対応する出力幾何を左右反転 |
| SVGに絵柄画像を含める | SVGへラスタライズ済みの絵柄を埋め込む |

## 面付け

### 通常面付け

絵柄と台座を1セットのタイルとして扱い、指定用紙へ複製します。

- 0度と90度を比較し、多く配置できる向きを自動選択
- 設定した隙間をタイル間へ適用
- 用紙外周にも同じ余白を確保

### 絵柄・台座の独立面付け

「絵柄と台座を別々に面付けする」を有効にすると、1枚の用紙内で両パーツを別々に配置します。

- 絵柄と台座を左右または上下の別領域へ配置
- 絵柄と台座それぞれについて0度・90度を評価
- 左右分割、上下分割、各回転の組み合わせを探索
- `min(絵柄数, 台座数)` が最大になる候補を採用
- 最終的な絵柄数と台座数を同数にそろえる
- プレビューには完成セット数を表示

### 隙間の扱い

- 絵柄同士、絵柄と台座、曲線部分を持つ台座同士は、設定した隙間を確保
- 用紙外周からも設定した距離を確保
- 台座外形の向かい合う両端に直線区間がある方向では、台座同士を隙間0mmで密着可能
- 円形など直線辺を持たない方向では、台座同士にも設定した隙間を適用

## 書き出しプレビュー

面付けのON/OFFにかかわらず、エクスポートパネルへ書き出し内容を表示します。

- 面付けOFFでは単体配置を表示
- 面付けONでは用紙全体と複製配置を表示
- 独立面付けでは絵柄配置と台座配置を個別に表示
- 絵柄、左右反転、枠、線色などの設定を反映
- 面付けON時は、指定した用紙サイズの外周枠を表示

プレビューとAI/PDF出力は共通の面付け幾何を使用し、表示と成果物の配置ずれを防いでいます。

## 出力形式

### Illustratorドキュメント (`.ai`)

PDF互換形式のIllustratorドキュメントを生成します。

- 絵柄画像を埋め込み
- 絵柄、差込口・台座、カットラインをレイヤー分離
- 実寸mmのページサイズ
- 通常面付けと独立面付けに対応
- 面付け用紙外周を編集可能な矩形パスとして出力
- 絵柄とカットラインの左右反転に対応

### カットラインAI (`-cutline.ai`)

- 絵柄画像を含めず、加工用の線だけを出力
- 通常面付けと独立面付けに対応
- 面付け用紙外周を矩形パスとして出力
- 赤色カットライン設定を反映

### 絵柄PDF (`-image.pdf`)

- カットラインを含めず、絵柄画像だけを実寸で出力
- 面付けと左右反転に対応
- 独立面付け時は完成セット数に合わせた絵柄数を配置

### SVG (`.svg`)

- 通常面付け、任意用紙サイズ、隙間、左右反転、赤色カットラインに対応
- 絵柄画像の埋め込みは任意
- 絵柄・台座の独立面付けは現在AI/PDF向けであり、SVGは従来の組配置を維持

  - 共通幾何をSVG表示へ変換する書き出しプレビュー
- `src/export/ai.ts`
  - PDF互換AI、カットラインAI、絵柄PDFの生成
- `src/export/svg.ts`
  - 実寸SVGの生成
- `src/analysis/imageLoader.ts`
  - PNG / SVGの絵柄読み込みとSVGの350dpiラスタライズ
- `src/components/ExportPanel.tsx`
  - 面付け・書き出し設定UI

## 検証

実装時に次の静的検査を実行し、成功しています。

- TypeScript: `tsc -b`
- ESLint: `eslint .`
- Prettier

ブラウザおよびAdobe Illustrator実機で、次の点は目視確認が必要です。

- SVG絵柄の表示、透明度、350dpi換算
- 各台座形状における直線辺の密着と曲線部の隙間
- 独立面付けのセット数と用紙外周余白
- Illustratorでのレイヤー、実寸、矩形パス、編集可否
